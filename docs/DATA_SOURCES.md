# Data Sources & References

Comprehensive list of all data sources, references, and resources used for vehicle information, parts data, repair guides, and technical specifications.

## Authoritative Reference Books

### Primary References
- **David Burgess Wise (2000)** - *The New Illustrated Encyclopedia of Automobiles*
  - Publisher: BookSales Inc
  - Pages: 560
  - ISBN: 978-0-7858-1106-0
  - Use: Historical vehicle data, production years, manufacturer information

- **G.N. Georgano (2000)** - *Beaulieu Encyclopedia of the Automobile*
  - Publisher: HMSO, London
  - ISBN: 1-57958-293-1
  - Use: Comprehensive automotive history, specifications, discontinued manufacturers

- **P. Roberts (1973)** - *A Picture History of the Automobile*
  - Publisher: Ward Lock Ltd, London, UK
  - ISBN: 0-7063-1301-1
  - Use: Classic vehicle history, visual references

- **Dennis E. Horvath** - *"Indiana Built"*
  - Source: Cruise-IN.com
  - Retrieved: January 24, 2015
  - Use: Regional automotive history, local manufacturers

## Online Reference Resources

### General Automotive References
- **Wikipedia** - Automotive articles, vehicle specifications, manufacturer history
  - **Orphan Cars** - https://en.wikipedia.org/wiki/Orphan_(car)
    - Definition of orphan car brands (manufacturers that ceased business entirely)
    - Historical context for discontinued manufacturers (DeLorean, Studebaker, Tucker, Nash, etc.)
    - Distinguishes complete manufacturer closures from discontinued marques
  - **Timeline of Motor Vehicle Brands** - https://en.wikipedia.org/wiki/Timeline_of_motor_vehicle_brands
    - Chronological timeline from 1852 to present
    - Tracks manufacturer emergence by year and country
    - Documents evolution of vehicle types (steam, electric, internal combustion)
    - Organized by historical eras (Veteran, Brass, Vintage, etc.)
    - Global coverage (US, France, UK, Germany, Italy, and more)
- **AutoEvolution.com** - Vehicle specifications, model years, technical data, reviews

### Service Manuals & Technical Documentation

## Data Source Usage Guidelines

### Quality Assurance
1. **Cross-reference data** from multiple sources when possible
2. **Verify part compatibility** before listing interchangeable parts
3. **Update regularly** - check for new model years, discontinued models
4. **Cite sources** when providing specific technical data

### Data Integrity
- Always note when data is from community sources vs. official manufacturers
- Mark historical/discontinued vehicles clearly
- Include date ranges for model availability
- Note regional variations (US vs. international models)

### Legal Compliance
- Respect copyright and fair use guidelines
- Use only publicly available or licensed data
- Properly attribute quoted material
- Follow API terms of service where applicable
