## Screenshot Guidelines

### Technical Requirements
- **Format**: PNG or JPEG
- **Desktop Size**: 1280x720 (16:9 ratio)
- **Mobile Size**: 750x1334 (iPhone 8 dimensions) or 1080x1920 (Android)
- **Quality**: High resolution, no compression artifacts
- **Content**: Actual app interface, no mockups

### Content Guidelines
- Show real features and functionality
- Use realistic data (avoid Lorem Ipsum)
- Highlight key features:
  - Vehicle search and diagnostics
  - Parts database
  - Web search integration
  - User dashboard
- Ensure text is readable
- Use consistent styling across screenshots

### For App Store Submissions

#### Google Play Store
- Minimum 2 screenshots required
- Maximum 8 screenshots
- Dimensions: 320px minimum to 3840px maximum
- Aspect ratio: 16:9 or 9:16

#### Apple App Store
- Requires screenshots for each device size
- iPhone: 1242x2688 (iPhone 11 Pro Max)
- iPad: 2048x2732 (12.9" iPad Pro)
- See [App Store Screenshot Specs](https://developer.apple.com/app-store/product-page/)

## How to Create Screenshots

### Option 1: Browser DevTools
1. Open app in Chrome
2. Open DevTools (F12)
3. Toggle device toolbar (Ctrl+Shift+M)
4. Select device size or custom dimensions
5. Capture screenshot:
   - Full page: Cmd/Ctrl+Shift+P → "Capture full size screenshot"
   - Viewport: Cmd/Ctrl+Shift+P → "Capture screenshot"

### Option 2: Actual Devices
1. Install PWA on physical device
2. Use device screenshot tools:
   - **iOS**: Power + Volume Up
   - **Android**: Power + Volume Down
3. Transfer screenshots to computer
4. Resize/crop if needed

### Option 3: Screenshot Tools
- [Screely](https://screely.com/) - Add browser frames
- [Shotsnapp](https://shotsnapp.com/) - Beautiful mockups
- [Screenshot.rocks](https://screenshot.rocks/) - Device frames

## Editing Guidelines

### Recommended Tools
- **Figma** - Professional design mockups
- **Adobe Photoshop** - Advanced editing
- **GIMP** - Free alternative
- **Preview/Paint** - Basic cropping

### Best Practices
- Crop to exact dimensions
- Remove sensitive user data
- Add annotations if helpful (arrows, highlights)
- Maintain consistent UI state (logged in, same user)
- Use real automotive data for authenticity
